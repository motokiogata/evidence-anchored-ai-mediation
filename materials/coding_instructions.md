# 交渉発言のコーディング依頼

交通事故の過失割合をめぐる交渉実験で、参加者（被害者A）が書いた発言が 742 件あります。
各発言について、争点ごとの態度（stance）を判定してください。

## ファイル
- `items.csv`：`item_id, codebook_id, text`（1行＝1発言。text に改行を含むものがあります）
- `codebooks.json`：`codebook_id` ごとの判定基準（`system_prompt`）と、判定する争点キー（`keys`、各2個）

## やること
1. 各行について、その `codebook_id` の `system_prompt` を判定基準として `text` を読む。
2. `keys` の争点それぞれに `assert` / `deny` / `concede` / `none` のどれか1つを付ける。
3. 結果を CSV で返す。列は `item_id,key,stance`。全 item_id × 全キー（1484 行）を漏れなく。

## 守ってほしいこと
- **1件ずつ文を読んで判定する**こと。キーワード検索・正規表現・スクリプトによる機械的な分類はしない。
- 判定基準は `system_prompt` の文言だけ。事故の実際の事実がどうだったかは推測しない（与えていません）。
- 発言はその1文だけで判定する（前後の文脈はありません）。
- 件数が多いので、100件程度ずつに分けて処理してかまいません。最後に全件を1つの CSV にまとめてください。
