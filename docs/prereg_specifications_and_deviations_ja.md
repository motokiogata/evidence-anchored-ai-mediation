## B. 登録後の逸脱
### B-1 欺瞞コーディングの信頼性確認を「人手20%」から「独立したLLMによる全件」に変更（2026-11-24）
- **登録内容（§5.4.1）**：無作為20%を2名が人手で二重コーディングし、κ≥.70 なら LLM 抽出を主指標、κ<.70 なら人手を主指標に切り替える。
- **変更**：人手ではなく、**実験で使っていない LLM** が、空でない主張文の**全件（742件）**を、実験時と同じコード表で再コーディングする。
  コーダーは Claude Opus 5.5（Bedrock API）と GPT（チャット画面経由）。実験時の抽出器は Claude Sonnet 4.6。
- **決めた時期**：確認的分析の結果を見た**後**（研究代表者の判断）。したがって事前規定ではなく逸脱として報告する。
- **理由**：この水準の判定（発言がどの争点を主張・否認・自認したか）で人手が LLM より正確とは考えにくく、全件を見られる利点がある。
- **結果（Opus 5.5、`analysis/recode_llm.py`、出力 `analysis/data/recode_reliability_20261124.txt`）**
  - スタンス（4分類）κ = **.674**（一致 84.0%、n=1,480）。試行の欺瞞あり/なし κ = **.656**（一致 83.7%、n=178）。**どちらも基準 .70 に届かない。**
  - 不一致はほぼ一方向：実験時の Sonnet が「主張/自認」と読み、Opus が「言及なし」とした（236件中 207件）。
    例：「A25:B75で提案」「相手は対向車の確認を怠って右折してきた」を Sonnet は「相手の違反を主張」と読んだ。
    Opus が欺瞞とした試行はすべて Sonnet も欺瞞としている（逆は25試行）。＝Sonnet が広く読みすぎ。
  - 欺瞞率（②③・分析対象159試行）：Sonnet 42.8% → Opus **27.0%**。
  - H1 を Opus のDVで推定し直す（感度分析）：OR = 0.83 [0.31, 2.25], p = .72（登録DVでは 0.88 [0.32, 2.41], p = .80）。**結論は同じ（不支持）。**
- **結果（GPT、2026-11-24 夕。チャット画面経由：`recode_llm.py export` の zip を渡し、返ってきた CSV を `import`。原本は `analysis/data/recode_gpt_return/`、出力 `analysis/data/recode_reliability_20261124b.txt`）**

  - 742件すべて取得。渡した原資料が改変されていないことを照合済み。
  - 一致度：Opus vs GPT はスタンス κ = **.842**（一致 94.3%）、試行の欺瞞あり/なし κ = **.597**（一致 86.0%）。
    Sonnet vs GPT はスタンス κ = .570、試行 κ = .360。
  - 3者は入れ子：GPT が欺瞞とした試行 ⊂ Opus ⊂ Sonnet。読みの厳しさの違いで、食い違う方向の不一致はほぼ無い。
    GPT は「争点の事実そのものを明言したか」で最も厳しい（例：「確認せず右折してきた」は「早回り右折」の主張としない。「こちらに過失はない」は速度超過の否認としない）。
  - 欺瞞率（②③・159試行）：Sonnet 42.8%（言い立て57・否認23）／Opus 27.0%（29・23）／GPT 13.8%（16・8）。「2コーダー一致」は GPT と同じ 13.8%。
  - **GPT の基準の位置づけ（2026-11-24 夜・研究代表者の指摘を受けて）**：GPT の読み方は世間一般の感じ方より狭い。
    Opus が主張/否認とし GPT が「言及なし」とした発言を確認すると、自分に落ち度がある事故（③）で
    「私は普通に走っていた」「交通規則を遵守して運転していた」と述べたものが含まれる（争点を名指ししていないので GPT は数えない）。

  試行の欺瞞あり/なしでは満たさない（κ=.60）。したがって欺瞞率は一つの数字に決めず、
  **「明言した嘘」（2コーダー一致、13.8%）を下限、登録DV（42.8%）を上限**として幅で報告する（主に据える指標の最終決定は研究代表者）。
- **影響の範囲**：実験中の「露見」の判定と表示も Sonnet のスタンスに基づいていた。読みすぎの分だけ、
  参加者が明言していない主張について「証拠と食い違う」と示された可能性がある（調停AIの提案割合は証拠だけで決まるので、合意割合・乖離には影響しない）。
